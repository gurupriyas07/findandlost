## Project Description
Lost & Found Web Application allows users to register, report lost items, and upload photos to help recover them. Users can manage only their own posts and view all submitted items in a clean, easy-to-use dashboard.

---

## Problem Statement
People often lose personal items like keys, wallets, or electronics, and there is no centralized platform to report or recover these lost items, leading to frustration and permanent loss.

---

## Solution
This web application provides a user-friendly platform where users can register, post lost items with descriptions and images, and manage only their own posts. The dashboard allows easy tracking and recovery of lost belongings.

## Implementation

### Installation
1. Download or clone the project folder.  
2. Open VS Code → File → Open Folder → select project folder.  
3. Right-click `index.html` → Open with Live Server (or open directly in browser).  

### Run
- Open `index.html` in any browser.  
- No backend required; data is stored locally using LocalStorage.

### System Architecture
The application is **frontend-only**. HTML pages interact with JavaScript, which stores user and lost item data in LocalStorage. The dashboard retrieves and displays this data.

### Application Workflow
1. User registers → credentials saved in LocalStorage.  
2. User logs in → redirected to dashboard.  
3. User adds lost items → stored in LocalStorage.  
4. User manages only their own posts → can delete/update items.
